# 收款渠道展示收款码

在「设置 → 收款码」分别上传微信与支付宝的 JPG/PNG/WebP 原图（单张不超过 3MB）。收款窗口及待收款订单补收窗口共用同一组件，选择微信/支付宝自动展示对应图片，选择现金隐藏图片。可点击图片放大，展示实收金额，按返回或 Escape 回到收款表单。

收款码是用户账户数据（db.paymentCodes），通过现有云端保存机制同步，不包含在公开源码或演示种子中。预览模式单独使用当前浏览器的 localStorage 保存，刷新可保留，换设备需重新上传；预览配置不会注入正式账户。JSON 导出包含收款码，应按账户备份保存。

图片为固定收款码，不动态嵌入订单金额，不会自动查询到账；顾客核对收款人和金额，经营者核实到账后再确认收款。

已在本地验证用户提供的两张图片上传、预览刷新保留、微信/支付宝切换、现金隐藏、放大/返回/Escape 与手机布局。正式账户云同步及真实扫码付款需在正式环境验收，本轮不发起付款或确认真实到账。
